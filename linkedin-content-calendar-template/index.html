Free LinkedIn content calendar template

A spreadsheet with a four-week plan already filled in, three posts a week. Write over the example and you have a month of LinkedIn posts planned. It opens in Excel and Google Sheets, and you do not need to sign up.

Download for Excel.xlsx Download as CSV.csv

Last updated November 25, 2026 · Free, nothing to sign up for. Using Google Sheets? Here is how to open it.

What is in the template

The Excel file has two sheets. The CSV file has the first one only.

  • Content calendar. One row per post, with 12 example rows (four weeks, three posts a week) and room for more. The columns are Week, Date, Day, Pillar, Format, Hook, Main point, Call to action, Status, Link after posting and Notes.
  • Content pillars. The topics you return to, with what each covers and an example post. Excel only.
  • Lists to pick from. Format (Text, Carousel, Poll, Graphic) and Status (Idea, Drafted, Ready, Posted) are dropdown lists in the Excel file, and the Day column fills in from the date.

The example posts are made up. They show how much to write in each column, so replace them with your own.

How to fill it in

  1. Start with the pillars. On the Content pillars sheet, replace the four examples with two to four topics you can write about for months.
  2. Set the dates. Change the first date to your own Monday, and the rest to the days you will post.
  3. Write the hook first. The hook is the first line or two, the part people see before “see more”, so write it before anything else in the row. You can test one in the free hook preview.
  4. Add the main point and the call to action. One sentence each is enough. The call to action is what you want the reader to do, even if it is only to comment.
  5. Move the status along. Idea, Drafted, Ready, then Posted.
  6. Paste the link after posting. A column of links makes it easy to find a post you want to reuse later.

How to open it in Google Sheets

  1. Download the Excel file above.
  2. Open Google Sheets and start a new blank spreadsheet.
  3. Choose File, then Import, then the Upload tab, and select the downloaded file.
  4. Under “Import location”, choose Replace spreadsheet, then Import data.

The CSV file imports the same way, but you get one sheet and no dropdown lists.

How many posts a week?

There is no number that works for everyone. The template starts at three a week because that fills a month with twelve posts and shows a mix of formats, but one or two a week is a good start if you are new to posting.

Pick the pace you can keep for months. If you miss two weeks in a row, lower the number and keep going. To change the pace in the file, delete rows or copy a row down.

Questions

Template questions

How many times a week should I post on LinkedIn?

Pick a pace you can keep for months. The template starts at three posts a week, but one or two a week is fine. A steady rhythm is easier to keep than bursts, so lower the number if you miss weeks.

How do I use this template in Google Sheets?

Download the Excel file, open Google Sheets, choose File, then Import, then Upload, and select the file. Pick Replace spreadsheet. The Status and Format lists come with it. If you use the CSV file instead, you get one sheet and no lists.

Which file should I download, CSV or Excel?

Download the Excel file if you use Excel or want the dropdown lists and a second sheet for your content pillars. Download the CSV file if you want plain text that opens in any spreadsheet app.

What is a content pillar?

A content pillar is a topic you return to again and again, such as lessons learned, how you work, client stories or your opinions. Two to four pillars give you something to write about each week without starting from a blank page.

Can I change the columns?

Yes. It is your copy. Delete a column you do not need, rename one, or add columns for things like the image or the person who reviews the post.

Is the template really free?

Yes. There is nothing to sign up for. Briopost is a separate tool that puts the same plan on a calendar, and it is in a free beta by invitation.
