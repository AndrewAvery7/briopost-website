LinkedIn carousel size checker

Pick a slide picture or the PDF you plan to post. You’ll see its size, its shape and how many pages it has, and whether it matches the portrait, square or story sizes Briopost makes.

Choose a file

PNG, JPG, WebP or PDF. You can also drop a file here.

Nothing is uploaded. Your browser reads the file on this device, and it never leaves it.

The sizes it checks

The sizes Briopost makes.

Carousels come in three shapes. Portrait takes up the most room in a phone feed, which is why most people use it.

Pictures and PDFs are measured differently

A picture has a size in pixels. A PDF page has a size in points, a print measure, so a 4:5 page can be 1080 x 1350 points or 432 x 540. For a PDF the checker compares the shape, which is what decides how the slides look in the feed.

How it reads your file

Pictures are opened by your browser the same way it shows any image. For a PDF, a small reader on this page counts the pages and reads each page’s size from the file itself. Nothing is sent to Briopost or anyone else.

Every slide the same size

A carousel looks cleanest when every page shares one size. When a PDF mixes sizes, the checker says so.

LinkedIn’s own limits

LinkedIn sets its own limits for document posts, such as file size and page count, and can change them. Check LinkedIn Help before you post a very long or very large file.
